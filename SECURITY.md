# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Email **privacy@ytosko.dev** with a description, steps to reproduce and the affected version.
You'll get an acknowledgement within a few days. Once a fix is released, we're happy to credit you.

## Scope

- The Neutrino Android app (this repository)
- The website at https://neutrino.ytosko.dev (`web/`)

Neutrino has no backend servers. API keys you use with Neutrino belong to your AI provider account;
if you believe a key is exposed, revoke it with your provider immediately.
